# acpanackal.github.io

This repository contains the source for my personal portfolio website, hosted via GitHub Pages.

## Overview

The site is a simple static HTML portfolio and is published from the repository root.

## Local development

Open `index.html` in a browser to view the site locally.

If you want to serve it locally with a simple web server, you can run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Deployment

Changes pushed to the default branch are published through GitHub Pages for the `acpanackal.github.io` site.
